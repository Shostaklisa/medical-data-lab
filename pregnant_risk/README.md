# Pregnant Risk (2-step model)

## Описание проекта
Прогностическая модель рисков беременных.  
Проект направлен на мультиклассовую классификацию уровня риска беременности (`low`, `mid`, `high`) на агрегированном датасете, где повторяющиеся наблюдения учитывались через веса (`count`). Основная цель — построение модели, которая минимизирует критические ошибки, особенно занижение высокого риска.

## Данные

| Параметр        | Описание                                           |
|-----------------|---------------------------------------------------|
| Age             | Возраст женщины на момент беременности            |
| SystolicBP      | Систолическое АД (мм рт.ст.)                     |
| DiastolicBP     | Диастолическое АД (мм рт.ст.)                    |
| BS              | Уровень глюкозы в крови (ммоль/л)               |
| BodyTemp        | Температура тела у беременных                     |
| HeartRate       | Частота сердечных сокращений в покое             |
| Risk Level      | Целевая переменная: уровень риска (`low/mid/high`)|

## Этапы работы

1. **Загрузка библиотек и данных**  
2. **Предобработка данных**  
   - Перевод названий столбцов в `snake_case`  
   - Проверка пропусков, типов данных, дубликатов  
   - Агрегация дубликатов с учетом веса `count`  
   - Исправление ошибок (например, опечатка в HeartRate 7 - 70)  
3. **Исследовательский анализ данных (EDA)**  
   - Описательная статистика  
   - Гистограммы, боксплоты, пайчарты  
   - Анализ распределения классов  
4. **Корреляционный анализ**  
   - Spearman: высокая зависимость у `blood sugar`, далее - давление  
   - Дополнительно оценена phik-корреляция  
5. **Подготовка датасета для ML**  
   - Разделение на тренировочную и тестовую выборки  
   - Кросс-валидация без выделения отдельной валидации  
6. **Baseline**  
   - Logistic Regression (multinomial) без масштабирования признаков  
   - Хорошо определяет low risk, слабое место - mid risk  
7. **Основная модель**  
   - CatBoost с гиперпараметрами: `depth=8`, `iterations=100`, `learning_rate=0.04`  
   - Поддержка весов `count`  
8. **Feature engineering**  
   - Добавление признаков: `pulse_pressure`, `hypertension`, `hyperglycemia` — существенного улучшения не дало  
9. **Иерархическая двухшаговая модель**  
   - Шаг 1: отделение low risk от mid/high  
   - Шаг 2: разделение mid vs high  
   - Результаты: Macro F1 ≈ 0.63–0.64, Accuracy ≈ 0.63  
   - Практически отсутствуют ошибки high - low  

## Основные наблюдения
- Двухшаговая модель безопаснее для критических ошибок, хотя базовая модель CatBoost показывает лучшие метрики.  
- Необходимо уточнение данных: уровни глюкозы, возрастные экстремумы, источники дубликатов.  
- Feature importance можно дополнительно исследовать (Shap, permutation), но признаки ограничены.
